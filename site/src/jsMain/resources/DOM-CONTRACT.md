# DOM-CONTRACT - what the integrator's Kotlin can rely on

Design agent, 2026-09-20. Scope: `site/src/jsMain/resources/`. Everything here was generated by
`_design/build_pages.py` from `scratch/content/*`; rerun it after a content change, never hand-edit the
HTML. `_design/check_pages.py` must stay at 0 failures.

The pages are complete documents with JavaScript off. Kotlin ENHANCES them: it never has to create
copy, only to fill slots, flip attributes and move cards. Every string Kotlin needs at runtime is
already in the DOM as text, as a `data-template`, or as a `data-msg-*` / `data-err-*` attribute, so
no fetch of `data/copy.json` is required (it is there if you prefer it).

This file and `_design/` are tooling. They are copied to dist like any resource; exclude them in
`copyDist` if you do not want them published (`exclude("DOM-CONTRACT.md", "_design/**")`).

## 0. Rules of the house

- CSP is `script-src 'self'; style-src 'self'` (infra/csp.txt). No inline `<script>`, `<style>`, `style=""`
  or `on*=""` exists in any page; keep it so. From Kotlin use CSSOM only: `el.style.transform = ...`,
  `el.style.setProperty("--vb-knob-turn", "0.4")`. Never `setAttribute("style", ...)`, never `innerHTML`
  with anything that came from the network or the URL. Use `textContent`.
- Tokens in templates: `{n} {total} {s} {ms} {i} {count} {pass} {id}`. Replace literally.
- Do not re-case strings. Do not add copy. If a string is missing, it is missing on purpose.
- Nothing in the DOM says which unlabeled switch does what, and nothing may.

Load order in `index.html` / `pricing.html`: `main.css` (webpack: @fontsource, all subsets) -> `styles/tokens.css`
-> `fonts.css` -> `type.css` -> `layout.css` -> `components.css` -> (`bloom.css`, index only) -> `print.css` (media=print)
-> `<script defer src="site.js">`. Legal pages and 404 do not load `main.css` or `site.js`.

`styles/api-page.css` is for site-api's bare pages: run it with `PAGE_STYLESHEET=/styles/api-page.css`.

`site.js` runs on TWO pages. Branch on `<html data-page>`: `index` (bloom, HUD, tour, sign, waitlist),
`pricing` (reduced-fee form, New Calendar dates, member counter; NO bloom). `legal` and `notfound` never load it.

## 2. `<html>` attributes (the global switches)

| attribute | values | who sets it | effect |
|---|---|---|---|
| `data-theme` | `absinthe-abyss` \| `nightshade-herbarium` (aliases `abyss`, `herbarium` also styled) | static = `absinthe-abyss`; Kotlin by local hour (night 19:00-07:00) or `#sw-daynight` | whole palette. After changing it call `PaletteDom.read()` again and `renderer.setPalette`. Also update `<meta name="theme-color">` (`#020a07` / `#efe8d8`). |
| `data-page` | `index` \| `pricing` \| `legal` \| `notfound` | static | see above |
| `data-js` | `on` | **Kotlin, first thing in `main()`** | reveals every `.vb-js-only`, hides every `.vb-nojs-only`. Until it is set the HUD, tour bar, clock, canvas host and card layer are `display:none`. |
| `data-sign-state` | `unknown` `loading` `down` `parked` `cold` `open` `degraded` `stale` | Kotlin | colours the sign board frame |
| `data-stage` | absent \| `full` | Kotlin, optional | `full` = `#stage` becomes `position:fixed` behind the page (full-viewport ZUI); `#doc` scrolls over it on solid ground. Default (absent) = the stage sits in the hero's right column (below the copy on phones). |
| `data-reduced-motion` | `on` | Kotlin when `#sw-slow` is on | kills chrome transitions. CSS also honours `prefers-reduced-motion`. The bloom itself only slows (`world.reducedMotion`), never stops. |

### 3.2 Cards and LOD

One `article.vb-pour` per pour lives in the pour list (the no-JS document). For the ZUI, CLONE it:

```kotlin
val card = article.cloneNode(true) as HTMLElement
card.removeAttribute("id")                 // ids must stay unique; inner ids (pour-<id>-name) too: remove or ignore
card.setAttribute("data-lod", "far")       // far | mid | near
cardsLayer.appendChild(card)
```

`data-lod` on the card: `far` = order code chip only, `mid` = + name, size, tap state, marks, `near` = everything.
It works through `data-lod-min="mid|near"` on the inner parts, so the same rule serves `article.vb-pass` clones.
Suggested thresholds from `CardAnchor.pxPerUnit`: far < 60, mid < 160, near >= 160 (tune freely).
`data-highlight="true"` on a card = focus frame.

`article.vb-pour` attributes: `data-pour-id` (order code), `data-shelf` (`well|call|top`), `data-order` (1-11),
`data-ring-id` (0-9 = `PourList` order; `-1` for `horror`), `data-pourable`, `data-thinking`, `data-house-pour`,
`data-guest-tap`, `data-on-order` (all `"true"|"false"`), and **`data-tap`** = `unknown|warm|cold|parked`
(Kotlin writes this from `/api/status`; `horror` has none). Inside: `[data-slot="tap-word"]` and
`[data-slot="tap-help"]` take the words; the words are on `section#pours` as
`data-tap-warm`, `data-tap-warm-help`, `...-cold...`, `...-parked...`, `...-unknown...`.
Update the list article AND any clone.

`a[data-pass]` (on pour cards, pass cards, anywhere): clicking means "waitlist with this pass":
set `#wl-pass.value = data-pass`, set `#wl-source.value = data-source`, show `#wl-pass-note`
(fill its `data-template`, `{pass}` = Well | Call | Top Shelf), go to `#list`. From `pricing.html` the same
buttons link to `index.html?pass=<well|call|top>#list`: read `?pass=` on load and do the same.

### 3.5 HUD `aside#hud` (js-only)

- `button#hud-toggle[aria-expanded][aria-controls=hud-panel]` + `div#hud-panel[hidden]`: toggle `hidden`,
  `aria-expanded`, and `#hud[data-open]`. Both labels are inside the button (`[data-when=closed|open]`).
- Knobs: `div.vb-knob[data-knob=rho|drift|louche]` > `input[type=range]#knob-<k>` + `output#knob-<k>-out`.
  rho 25..45 step 0.1 (28), drift 0.02..4 step 0.01 (1), louche 0..1 step 0.01 (0.35).
  On `input`: write the output text and `knob.style.setProperty("--vb-knob-turn", fraction0to1)`: the dial turns
  -135deg..+135deg. Map to `world.rho`, `world.driftRate`, `renderer.setLouche`. The range input lies invisibly
  over the dial: drag left/right, arrow keys, Home/End all work natively.
- Bell: `button#bell[data-state=idle|ringing]`, strings `data-msg-ringing`, `data-msg-answered` (`{ms}`),
  `data-msg-no-answer` -> `p#bell-status[role=status]`.
- Switches: `input[role=switch]` `#sw-daynight` (name `dayNight`), `#sw-tilt` (`tilt`), `#sw-slow` (`reducedMotion`);
  unlabeled `#sw-u1 .. #sw-u4` (`aria-label="Unmarked switch n"`, no visible text). Each `label.vb-switch[data-switch]`.
  `#sw-daynight`: initialise `checked` = (current theme is night); a flip is the override; `#hud-reset` returns to the clock.
  Every flip of every switch injects `BloomConfig.switchEpsilon`.
- `button#hud-reset` "LET GO".
- The panel title appends the active theme name through CSS (`--vb-theme-name`); nothing to do.

## 7. JSON shapes in `data/`

- `models.json` - verbatim copy of content. `{asOf, shelves:[{id,name,order}], models:[10 x {id, order, displayName,
  maker, hfRepo, hfUrl, size, paramsB, architecture, base, shelf:"well|call|top", flavour:[..], decensor:string|null,
  tastingNote, guestTap, thinking, housePour, ring, pourable, onOrder, coldStartSeconds, coldStartMaxSeconds}],
  onOrder:[{... id:"horror", ring:false, pourable:false}]}`. `models[i]` is ring id `i`.
- `pricing.public.json` - verbatim copy of content's PUBLIC file (never `pricing.json`). `{asOf, shelves:[{id, models,
  thinkingModels, housePour, inputPerMtok, outputPerMtok, minPour:{warm,cold}, ...}], passes:[{id, priceMonth, tabCredit,
  shelves, rpm, concurrency, taps, writingHours:{headlineText, headline:{context6k,context16k}, ...}, cta}], topUps,
  patron, reducedFee:{ladder, formFields, ...}, volumeSchedule, disclaimers:[..], acceptableUse:[..]}`.
  Do NOT render `shelves[].coldStartNote` (the Top Shelf one names a card size) or `roughGuide` without its context figures.
- `copy.json` - content's copy.json with every `_`-prefixed key REMOVED (builder notes), plus
  `meta: {asOfFallback: "20 September 2026", tokens: [...]}`.
- `seo.json` - minus `_notes`. Already baked into every `<head>`; og:image is omitted because `og.png` does not exist.
- API: `GET /api/status`, `GET /api/models`, `POST /api/subscribe`, `POST /api/reduced-fee` - shapes in site-api/README.md.
